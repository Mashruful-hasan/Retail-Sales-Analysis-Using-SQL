# Retail Sales Analysis Using SQL

## Project Overview

**Project Title:** Retail Sales Analysis

This project focuses on analyzing retail sales data using **MySQL** in **MySQL Workbench** to explore customer purchasing behavior, product category performance, sales trends, and profitability.

The project demonstrates essential SQL skills commonly used by Data Analysts, including data exploration, data cleaning, aggregation, filtering, temporary tables, subqueries, and window functions.

By analyzing retail transactions, this project aims to answer business questions and generate insights that can support data-driven decision-making.

## Project Objectives

1. **Database Setup:** Work with a retail sales database using MySQL.
2. **Data Cleaning:** Identify and handle missing or NULL values.
3. **Exploratory Data Analysis (EDA):** Explore the dataset to understand its structure, customers, and product categories.
4. **Business Analysis:** Investigate sales performance, customer behavior, product demand, and profitability.
5. **Sales Insights:** Identify high-performing product categories, top customers, and monthly sales patterns.

## Tools and Technologies

- **Database Management System:** MySQL
- **SQL Development Environment:** MySQL Workbench
- **Language:** SQL

## 3. Business Analysis and SQL Queries

The following 11 business questions were answered using SQL queries.

### Q1. Retrieve all columns for sales made on November 5, 2022.

```sql
SELECT *
FROM retail_sales
WHERE sale_date = '2022-11-05';
```

**Objective:** Retrieve all transactions that occurred on a specific date.

### Q2. Retrieve Clothing transactions with a quantity of at least 4 in November 2022.

```sql
SELECT *
FROM retail_sales
WHERE category = 'Clothing'
  AND DATE_FORMAT(sale_date, '%Y-%m') = '2022-11'
  AND quantiy >= 4;
```

**Objective:** Identify clothing transactions with higher purchase quantities during November 2022.

### Q3. Calculate total sales for each product category.

```sql
SELECT
    category,
    SUM(total_sale) AS Total_Sale
FROM retail_sales
GROUP BY category;
```

**Objective:** Compare the total sales revenue generated by different product categories.

### Q4. Find the average age of customers who purchased products from the Beauty category.

```sql
SELECT
    category,
    AVG(age) AS Average_Age
FROM retail_sales
WHERE category = 'Beauty'
GROUP BY category;
```

**Objective:** Understand the average age of customers purchasing Beauty products.

### Q5. Retrieve all transactions where the total sale amount is greater than 1000.

```sql
SELECT *
FROM retail_sales
WHERE total_sale > 1000;
```

**Objective:** Identify high-value transactions and understand premium purchasing behavior.

### Q6. Find the total number of transactions made by each gender in each product category.

```sql
SELECT
    category,
    gender,
    COUNT(transactions_id) AS Total_transaction
FROM retail_sales
GROUP BY category, gender;
```

**Objective:** Analyze transaction distribution across genders and product categories.

### Q7. Calculate the average sale for each month and identify the month with the highest average sale in each year.

**Step 1: Create a temporary table**

```sql
CREATE TEMPORARY TABLE Monthly_Sales
SELECT
    YEAR(sale_date) AS Year,
    MONTH(sale_date) AS Month,
    ROUND(AVG(total_sale), 2) AS Average_Sale
FROM retail_sales
GROUP BY YEAR(sale_date), MONTH(sale_date)
ORDER BY Year, Month;
```

**Step 2: Identify the highest-average month using `RANK()`**

```sql
SELECT *
FROM (
    SELECT
        Year,
        Month,
        Average_Sale,
        RANK() OVER (
            PARTITION BY Year
            ORDER BY Average_Sale DESC
        ) AS Ranking
    FROM Monthly_Sales
) AS Ranked_Sales
WHERE Ranking = 1
ORDER BY Year;
```

**Objective:** Analyze monthly average transaction values and identify the month with the highest average in each year.

### Q8. Find the top 5 customers based on their highest total sales.

```sql
SELECT
    customer_id,
    SUM(total_sale) AS Highest_Sale
FROM retail_sales
GROUP BY customer_id
ORDER BY Highest_Sale DESC
LIMIT 5;
```

**Objective:** Identify the five highest-spending customers based on their cumulative sales.

### Q9. Find the number of unique customers who purchased products from each category.

```sql
SELECT
    category,
    COUNT(DISTINCT customer_id)
FROM retail_sales
GROUP BY category;
```

**Objective:** Understand customer distribution across product categories without counting the same customer multiple times within a category.

### Q10. Identify which product categories sell the most units.

```sql
SELECT
    category,
    SUM(quantiy) AS Total_Quantity_Sold
FROM retail_sales
GROUP BY category
ORDER BY Total_Quantity_Sold DESC;
```

**Objective:** Determine the most popular product categories based on the total number of units sold.

### Q11. Identify which product categories generate the most profit.

```sql
SELECT
    category,
    SUM(total_sale) AS Total_Revenue,
    ROUND(SUM(cogs), 2) AS Total_COGS,
    ROUND(SUM(total_sale - cogs), 2) AS Total_Profit
FROM retail_sales
GROUP BY category
ORDER BY Total_Profit DESC;
```

**Objective:** Evaluate the profitability of each product category by comparing total revenue against the cost of goods sold (COGS).
